# ЯМО

ЯМО — русскоязычный язык программирования.

Цель проекта — самостоятельный компилятор, который собирает программы на ЯМО без зависимости от внешних компиляторов.

## Текущее состояние

Доказано, что ЯМО умеет:

- работать с буферами;
- добавлять байты;
- читать файлы;
- распознавать слова и числа;
- генерировать машинный код x86-64;
- создавать исполняемый ELF-файл;
- запускать созданный ELF-файл.

## Состав репозитория

В git хранятся только исходные файлы:

- README.md
- .gitignore
- самохостинг/компилятор.ямо

Скомпилированные .elf файлы не хранятся в git.

## Сборка и проверка

```bash
./ямо_нативный самохостинг/компилятор.ямо -o самохостинг/компилятор.elf
./самохостинг/компилятор.elf
./самохостинг/тест.elf
echo $?
```

Ожидается код завершения 42.

## Синтаксис

```ямо
целое x = 10;
вывод x;

функция удвоить(целое n) {
    вернуть n * 2;
}

вывод удвоить(21);
```
