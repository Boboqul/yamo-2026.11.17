# Кирпичный самохостинг ЯМО

Главное правило: ЯМО развивается только на ЯМО.

## Принцип

Каждый кирпич — отдельная программа на ЯМО.
Каждый следующий кирпич собирается предыдущим бинарником ЯМО.
Внешние языки не участвуют в развитии после появления первого ямо.elf.

## Стартовое исключение

Для самого первого запуска нужен уже полученный бинарник ЯМО.
Если его нет, допускается одноразовый стартовый мост только ради рождения первого ямо.elf.
После этого мост перестаёт участвовать в развитии языка.

## Кирпичи

1. 01_буфер.ямо — проверка работы с буферами.
2. 02_эмиттер.ямо — генерация машинных байтов.
3. 03_лексика.ямо — чтение слов, чисел и строк.
4. 04_разборщик.ямо — распознавание ключевых слов ЯМО.
5. 05_переменные.ямо — таблица переменных.
6. 06_присваивание.ямо — запись значения в переменную.
7. 07_арифметика.ямо — сложение, вычитание, умножение, деление.
8. 08_вывод_чисел.ямо — печать целого числа.
9. 09_условия.ямо — если, иначе.
10. 10_циклы.ямо — пока.
11. 11_функции.ямо — объявление, вызов, возврат.
12. 12_строки.ямо — текст, длина, сравнение.
13. 13_массивы.ямо — индексация и хранение данных.
14. 14_ошибки.ямо — честная обработка ошибок и коды возврата.
15. 15_писатель_файла.ямо — создание исполняемого файла.
16. 16_сборщик.ямо — главный сборщик ЯМО.
17. 17_самохостинг.ямо — ЯМО собирает сам себя.

## Правила качества

-诊断 сообщения только на русском языке.
- Исходники .ямо только на кириллице.
- Никаких латинских имён в новых исходниках ЯМО.
- Ошибка должна возвращать честный код ошибки.
- При ошибке не создавать ложный выходной файл.
- Каждый кирпич обязан иметь тест.
- Следующий кирпич начинается только после успешного теста предыдущего.

## Цикл развития

```text
кирич_N.ямо
    собирается через
кирич_{N-1}.elf
    даёт
кирич_N.elf
    проходит тест
    фиксируется в git
Принято. Убираем лишнее. Дальше — **только кирпичи на ЯМО**.

## Железное правило

1. Каждый кирпич — это файл `.ямо`.
2. Каждый кирпич собирается предыдущим бинарником ЯМО.
3. После появления первого настоящего `ямо.elf` — никаких C, Python, LLVM, gcc, clang, ld в развитии языка.
4. Все сообщения об ошибках — на русском.
5. При ошибке — честный код ошибки и никакого ложного выходного файла.
6. Исходники ЯМО — только кириллица, без латинских букв.
7. Переходим к следующему кирпичу только после зелёного теста предыдущего.

## Единственная честная оговорка

Чтобы язык родился, нужен один стартовый бинарник.  
Но это не “развитие на другом языке”. Это только рождение первого `ямо.elf`.

После этого:

```text
ямо.elf собирает новый ямо.ямо
новый ямо.elf собирает ещё более новый ямо.ямо
и так далее
```

Без участия других языков.
